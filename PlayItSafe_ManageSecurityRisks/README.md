# Play It Safe: Manage Security Risks

## Overview
This folder contains security audit documentation, compliance checklists, and risk assessments conducted for a simulated organization (**Botium Toys**). The objective was to evaluate the company's cybersecurity posture against industry standards and align practices with the **NIST Cybersecurity Framework (CSF)**.

---

## 📄 Key Documents & Projects Included
* **Botium Toys Security Audit & Risk Assessment:** Evaluation of assets, vulnerabilities, and potential threats to internal and web infrastructure.
* **Controls & Compliance Checklist:** Gap analysis against regulatory standards including **GDPR** (data privacy) and **PCI-DSS** (payment processing).
* **Stakeholder Memorandum:** Executive summary providing remediation priorities, budget justifications, and strategic security recommendations to leadership.

---

## 🛠️ Key Skills Applied
* Risk Management & Threat Modeling
* NIST Cybersecurity Framework (Identify, Protect, Detect, Respond, Recover)
* Regulatory Compliance (PCI-DSS, GDPR, SOC 2)
* Security Controls Assessment (Administrative, Technical, and Physical)
