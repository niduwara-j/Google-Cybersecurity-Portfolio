# Connect and Protect: Networks and Network Security

## Overview
This folder documents practical investigations into network security, packet analysis, and system hardening. Projects focus on identifying unauthorized network traffic, analyzing DoS/DDoS attacks, and drafting incident response reports following the **NIST SP 800-61** lifecycle.

---

## 📄 Key Projects & Case Studies
* **SYN Flood Attack Analysis:** Investigation of a transmission control protocol (TCP) handshake exhaustion attack on internal web servers.
* **Network Traffic & Protocol Analysis:** Inspection of DNS and HTTP traffic logs to uncover unauthorized data exfiltration and malicious requests.
* **Operating System & Network Hardening:** Recommendations for network segmentation, port filtering, and firewall rule configurations.
* **NIST Incident Report Analysis:** Formal incident response post-mortem outlining containment, eradication, and recovery steps for a compromised web service.

---

## 🛠️ Key Skills Applied
* Network Protocols (TCP/IP, DNS, HTTP/HTTPS, ARP)
* Packet & Traffic Inspection (tcpdump, Wireshark principles)
* Network Hardening (Firewalls, IDS/IPS, Subnetting)
* Incident Triage & Documentation (NIST SP 800-61)
