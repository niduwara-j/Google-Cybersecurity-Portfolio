# Sound the Alarm: Detection and Response

## Overview
This directory covers incident detection, alert triage, and security monitoring using Intrusion Detection Systems (IDS) and Security Information and Event Management (SIEM) tools.

---

## 📄 Key Projects & Investigations
* **Intrusion Detection with Suricata:** Wrote and tested custom alert rules to detect network scans, signature-based malicious traffic, and unauthorized port usage.
* **SIEM Incident Investigation (Chronicle / Splunk concepts):** Parsed security telemetry to construct an attack timeline and investigate active breach indicators.
* **Incident Response Playbooks:** Drafted structured playbooks for detecting, containing, and remediating brute-force and malware incidents.

---

## 🛠️ Key Skills Applied
* IDS Rule Configuration (Suricata)
* SIEM Alert Triage & Correlation
* Indicators of Compromise (IoCs) Identification
* Incident Response Lifecycle (Containment, Eradication, Recovery)
