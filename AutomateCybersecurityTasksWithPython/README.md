# Automate Cybersecurity Tasks with Python

## Overview
This folder contains automation scripts created in Python to parse security logs, enforce network access controls, and automate routine administrative security tasks.

---

## 📄 Featured Project: Automated Access Control Algorithm
* **Objective:** Create an algorithm in Python that reads an IP allow list file, compares it against a list of revoked IP addresses, and updates the allow list to remove unauthorized entries.
* **Key Operations:**
  * File I/O handling (`open()`, `.read()`, `.write()`).
  * String parsing and conversion (`.split()`).
  * Conditional iteration and list management (`for` loop, `if ... in`, `.remove()`).
  * Data formatting with `.join()` to restore clean file structure.
