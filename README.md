## 📂 Projects Overview

### 1. Security Audit & Risk Assessment (NIST CSF)
* **Goal:** Performed a comprehensive security audit for a mock organization (Botium Toys) to identify compliance gaps, asset vulnerabilities, and operational risks using the NIST Cybersecurity Framework.
* **Key Findings:** Lack of centralized user permissions, missing firewall configurations, and unencrypted customer data.

### 2. Linux File Permissions & Security Management
* **Goal:** Audited and restructured user/group permissions across an internal server environment using Bash commands (`chmod`, `chown`, `ls -la`).

### 3. SQL Security & Log Investigation
* **Goal:** Investigated anomalous login attempts, potential data breaches, and machine patch levels by querying security database tables.

### 4. Incident Handling & Alert Analysis
* **Goal:** Analyzed network packet captures and triggered alerts using Intrusion Detection Systems (Suricata) to investigate a simulated DDoS and brute-force attack.

### 5. Automated Access Control with Python
* **Goal:** Developed a Python script to automate the removal of unauthorized IP addresses from an organization's network allow list.
